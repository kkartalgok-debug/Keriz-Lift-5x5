LIFT 5x5 — FREE iPHONE HOME SCREEN APP
Release: 1.1 (PWA)

This is a Progressive Web App (PWA). It installs from Safari onto your iPhone Home Screen.
It is NOT an App Store app and does not require an Apple Developer account or annual fee.

FASTEST FREE SETUP (GitHub Pages)
You need a free GitHub account and a computer for the initial upload.

1. On your computer, unzip lift-5x5-free-app.zip.
2. Sign in at https://github.com and create a new PUBLIC repository, e.g. lift-5x5.
3. Open the repository and choose Add file → Upload files.
4. Upload the CONTENTS of the unzipped folder (index.html, app.js, style.css, manifest.json, sw.js, and both icon PNGs). Do not upload only the ZIP.
5. Choose Commit changes.
6. Open repository Settings → Pages.
7. Under Build and deployment, select Deploy from a branch; choose branch main and folder /(root), then Save.
8. Wait for GitHub Pages to publish. It will show an HTTPS address, usually https://YOUR-USERNAME.github.io/lift-5x5/.
9. On your iPhone, open that HTTPS address in Safari (not an in-app browser).
10. Tap Share → Add to Home Screen → Add.
11. Open Lift 5x5 from the new Home Screen icon. Open it once while online so the app files are cached for offline use.

USAGE
- Workout A: Squat 5x5, Bench Press 5x5, Barbell Row 5x5.
- Workout B: Squat 5x5, Overhead Press 5x5, Deadlift 1x5.
- Tap each set tile to mark it complete. The rest timer starts automatically.
- When all prescribed sets are complete, Finish Workout increases the working weights.
- Defaults: kg; squat/bench/row/OHP +2.5 kg; deadlift +5 kg.
- Use +/- to adjust starting weights before logging sets.
- Warm-up calculator gives approximate warm-up loads.
- Data is saved locally in Safari on this iPhone. It does not sync to other devices.

IMPORTANT LIMITATIONS
- This app is an independent workout tracker inspired by a common 5x5 routine, not the official StrongLifts app.
- This release does not include cloud sync or automatic cloud backup. Clearing Safari website data or removing stored site data may erase your history. Keep your own backup if the data matters.
- The unit selector changes the displayed unit label only; it does not convert existing numbers. Set the correct unit before entering weights.
- If you miss prescribed reps, this version holds the weight rather than applying a full multi-failure deload algorithm.
- Warm-up suggestions are approximate. Use safe technique, appropriate loads, and a spotter/safeties when needed.

No paid developer account, App Store submission, or subscription is required for this installation method.
